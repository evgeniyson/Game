# Руины Рассвета

Воксельная RPG для браузера (Three.js + TypeScript + Vite), рассчитанная на телефоны и ПК. Деплоится на Vercel как статический сайт.

Через три века после «Тихого Цветения» природа поглотила города. Вы — Пробуждённый из лагеря выживших: исследуете бесконечные заросшие руины, охотитесь на мутировавших зверей, собираете ресурсы, создаёте снаряжение с рунами и бросаете вызов стражам поваленных Колоссов.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # проверка типов + сборка в dist/
npm test         # юнит-тесты (Vitest)
```

Деплой на Vercel: импортируйте репозиторий в Vercel — `vercel.json` уже настроен (framework `vite`, output `dist`).

## Графика «диорама»

- Пост-обработка: мягкое затенение (GTAO), глубина резкости + tilt-shift (эффект миниатюры), цветокоррекция по биому, виньетка, плёночное зерно. Сила размытия и качество графики меняются в меню (☰ → Графика / Диорама).
- Атмосфера биомов с плавными переходами: тёплые луга, оранжевая дымка пустыни, сине-фиолетовая зима, зеленоватый туман болот; снегопад, песчаная пыль, листопад, пыльца, светлячки.
- Блоки «собраны» из микро-вокселей (шейдер), неровная бахрома травы и снега на гранях, пена у берега.
- Тысячи травинок-«иголок» и мелкий мусор вокруг игрока: качаются на ветру и приминаются при ходьбе.
- Все декорации в мелком вокселе с вариантами (деревья с ветвями и градиентными кронами, камни со слоями, заснеженные сосны, кривые сухие деревья) и LOD.
- Места: пустынные руины (колонны, арки, акведук), заснеженные бревенчатые избы с заборами и фонарями, обломки самолётов и грузовиков с сундуками припасов.
- Детальный персонаж (≈33 вокселя в высоту): лицо с бликами в глазах и морганием, чёлка и длинные волосы с покачиванием, одежда слоями, плащ; головной убор меняется надетым предметом.
- Оружие и щиты из инвентаря видны на персонаже, светятся по редкости, руны — цветные камни; след от взмахов. Иконки снаряжения рендерятся из 3D-моделей.
- Атмосферная живность: лисы, птицы, бабочки, ящерицы, верблюды.

## Что есть в игре

- **Бесконечный генерируемый мир** из чанков 32×32×64 (генерация и построение мешей в Web Worker'ах, запечённое vertex AO). Биомы: Цветущие луга, Заросший мегаполис с руинами домов и дорогами, Тёмный лес, Ржавое болото, Пустошь, Снежные пики. Поваленные медные Колоссы с водопадами, лагерь выживших в центре. Цикл дня и ночи.
- **3 класса** со способностями в духе Dota 2 (Q/W/E + ульта R на 6/12/18 уровнях, правило прокачки Dota) и пассивками:
  - Страж (Сила): Удар щитом, Рывок, Шипастый панцирь, Разлом земли; пассивка «Тяжёлая рука».
  - Следопыт (Ловкость): Веер стрел, Капкан, Перекат, Град стрел; пассивка «Меткость».
  - Мистик Рун (Интеллект): Огненная сфера, Ледяная нова, Мерцание, Цепная молния; пассивка «Резонанс».
- **Таланты** на 10/15/20/25 уровнях (выбор 1 из 2).
- **Характеристики** Сила/Ловкость/Интеллект, броня по формуле Dota, сопротивление магии, крит, вампиризм, уклонение, сокращение КД, сила способностей, отражение урона.
- **Бафы и дебафы**: оглушение, заморозка, корни, немота, замедление, поджог, яд (стаки), кровотечение, раскол брони, проклятие; ускорение, регенерация, щиты, ярость, стойкость (иммунитет к контролю) и др.
- **Живность и враги**: олени, кролики-рогачи, кабаны (нейтральные), мусорные крабы, слизни (делятся при смерти), лозоволки (стаями), ржавые автоматоны, болотные жабы, ледяные слизни. Элиты с аффиксами (Бешеный, Каменнокожий, Ядовитый, Вампирический, Ледяной). Босс Каменный Молотоогр у каждого Колосса (телеграфируемый удар, бешенство на 50% HP).
- **Предметы**: 8 слотов экипировки, 5 редкостей со случайными аффиксами, гнёзда для рун, улучшение +1…+5 в кузнице, разбор на материалы. Активные предметы (Фазовый камень, Амулет стойкости, Тотем лечения, Ловчая сеть) и предметы с компромиссом (Кровавый клинок, Тяжёлые латы, Маска берсерка, Глаз бури, руны).
- **Крафт**: добыча ресурсов в мире (деревья, камни, машины, травы, кристаллы), станции в лагере (Верстак, Кузница, Алхимический стол, Рунный алтарь), сборка старших предметов из компонентов и младших предметов.
- **Задания** с доски наград (охота, сбор, крафт, награда за босса), уровни 1–30, боевая мощь, исследование регионов.
- **Сохранение** в localStorage (автосохранение, отдых у костра).

## Управление

- **Телефон**: касание левой половины экрана — джойстик; большая кнопка — атака (зажать; без врагов — добыча); способности: тап — по ближайшему врагу, перетягивание — прицел, увести палец на ✖ — отмена; «Auto» — автобой; «+» над кнопкой — изучить способность.
- **ПК**: WASD — движение, ЛКМ/Пробел — атака, Q/E/R/T — способности (зажать для прицела мышью), 1–4 — быстрые слоты, F — взаимодействие, I — сумка, C — крафт, K — навыки, G — автобой, колесо — зум, Esc — меню.

## Структура

```
src/core      — RNG, звук (WebAudio)
src/world     — генерация мира, мешер, воркер, стриминг чанков
src/render    — рендерер, воксельные модели, эффекты
src/combat    — характеристики, эффекты, способности
src/data      — классы, предметы, рецепты, бестиарий (декларативные данные)
src/items     — инвентарь, лут, крафт
src/game      — игровой цикл, игрок, мобы, задания, сохранение
src/input     — клавиатура/мышь и сенсорное управление
src/ui        — HUD, окна, меню
tests         — юнит-тесты
```
